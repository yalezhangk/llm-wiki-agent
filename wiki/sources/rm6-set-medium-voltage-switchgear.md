# RM6 SeT 中压开关柜技术规格与配置指南

本文档汇总了施耐德电气 RM6 SeT 中压开关柜的核心技术规格、功能模块参数、安全联锁要求、数字化解决方案及安装尺寸，作为该设备选型与维护的权威参考。

## 核心规格与寿命

RM6 SeT 主回路具有 **40年以上使用寿命**，且在寿命期内 **免维护** 且无需补气。设备采用 SF6 气体绝缘，具有极高的可靠性。

*   **额定电压 (Ur)**: 12kV 或 24kV
*   **额定电流**: 630A
*   **短时耐受电流**: 20kA (部分配置可达 25kA)
*   **气箱材质**: 3mm 304不锈钢，保证极低的气体泄漏率，并配备后部安全阀防止气体过压。

## 功能模块参数

RM6 SeT 支持多种功能模块组合，主要包括 C（三工位负荷开关）、F（负荷开关-熔断器组合）、V（真空断路器）及 D（提升柜）。

### C 功能：三工位负荷开关
*   **机械寿命 (M2)**: 5000 次
*   **短时耐受电流 (Ik)**: 20 kA (4/2 秒)
*   **联锁机制**: 三工位开关具备天然互锁特性，确保操作安全。详见 [[concepts/three-position-switch-and-interlocks|三工位开关与机械联锁]]。

### V 功能：真空断路器
*   **机械寿命 (M2)**: 10000 次
*   **开断能力 (Isc)**: 20 kA
*   **关合能力 (Ima)**: 50 kA
*   **分闸时间**: < 40 ms
*   **合闸时间**: < 60 ms
*   **重合闸能力**: 支持自动重合闸 (O-0.3s-CO-3min-CO)

### F 功能：负荷开关-熔断器组合
*   **转移电流**: 1750A (12kV) / 1000A (24kV)
*   **开断能力**: 31.5 kA
*   **联锁要求**: 熔断器室与接地开关具备联锁机制。

### 组合能力
*   支持最大 **6单元共箱** 自由组合。
*   **限制**: PT柜和M柜不能共箱。

## 安全联锁与环境要求

### 安全联锁
设备具备多重安全联锁机制，包括：
1.  三工位开关天然互锁。
2.  带电电缆联锁 (LCI)。
3.  熔断器室与接地开关联锁。
4.  隔离开关操作限制。

### 操作环境条件
*   **环境温度**: -25℃ 至 40℃。
    *   *注意*: 低于或等于40℃，高于或等于-25℃（低温使用请咨询施耐德电气）。
*   **海拔**: ≤ 1000m。
*   **湿度**: ≤ 95% (24h) / 90% (1月)。

## 数字化与保护

RM6 SeT 支持数字化状态监测，通过物联网连接 EcoStruxure 资产管理软件，实现状态监测与资产管理。

### 保护继电器
*   **型号**: Easergy P1
*   **功能**: 提供过电流、接地故障、热过载及自动重合闸保护。
*   **通信**: 支持 Modbus / IEC60870-103。
*   **防护等级**: 前面板 IP54。
*   **工作温度**: -40℃ 到 +70℃。
*   **语言**: 提供 8 种操作语言。
*   详见 [[entities/easergy-p1|Easergy P1 保护继电器]]。

### 监测装置
*   **PD110 系列局放监测装置**: 测量范围 0-30000pC，可识别局放类型。
*   **Easergy TH110/TH110-R**: 无线智能传感器，用于关键电源连接的连续性温度监视。

## 安装与土建要求

### 柜体尺寸
*   **单功能柜**: 宽 375/420mm，深 750mm，高 1950mm（含 350mm 低压室）。
*   **6功能柜**: 长 2170mm。
*   **负荷开关柜/母线提升柜**: 宽 375mm × 深 750mm × 高 1950mm（含 350mm 低压间）。

### 安装间距
*   单元到后墙距离: ≥ 20mm。
*   单元到房顶距离: ≥ 100mm。
*   可扩展侧面到墙距离: ≥ 450mm。

### 防护等级
*   **前面板**: IP54
*   **继电保护外壳**: IP40
*   **接线端子**: IP20

### 电缆连接
*   **套管**: 配备 630A 套管，提供短、中、长三种规格可选，支持单/双/三电缆安装。
*   **电缆附件**: 配套 SE 系列电缆附件，最高系统电压 24kV，持续额定电流 630A，适用电缆截面 25~400mm² (15kV)。
*   **避雷器**: 17kV 后插式避雷器，持续运行电压 Uc 为 13.6kV，标称放电电流下残压 ≤ 50kV。
*   详见 [[entities/se-series-cable-accessories|SE系列电缆附件与避雷器]] 和 [[concepts/rm6-set-installation-requirements|RM6 SeT 安装与土建要求]]。

# 短路电流计算

短路电流计算是电力系统设计与保护整定的核心环节，旨在确定不同故障点（K1, K2, K3）在对称及不对称故障条件下的电流水平。本文档基于基准参数设定，详细阐述计算公式及各故障点的具体计算结果。

## 基准参数设定

在进行短路电流计算前，需统一基准值以简化标幺值运算：
*   **基准容量 ($S_b$)**：设定为 **100 MVA**。
*   **基准电压 ($U_B$)**：选取**平均额定电压**。
*   **线路电抗计算公式**：
    $$ X_{1*} = x_0 \times L \times \frac{S_B}{U_B} $$
    其中 $x_0$ 为单位长度电抗，$L$ 为线路长度。

## 对称短路电流计算结果

对称短路（三相短路）电流通常用于校验断路器的开断能力。各关键故障点的计算结果如下：

### 110kV 母线侧 (K1点)
*   **0s时刻短路电流 ($I''_{0s}$)**：**2.22 kA**。
    *   计算依据：$I_{0s}^{\prime\prime} = 0.4314 \times 3.263 + 0.3216 \times 2.510 = 2.22 \text{ kA}$。

### 10kV 母线侧 (K3点)
*   **未加装电抗器时**：总短路电流 ($I''_{K3}$) 为 **35.96 kA**。
*   **加装电抗器后**：总短路电流 ($I''_{K3}$) 降至 **23.54 kA**，满足小于 25 kA 的限制要求。

## 不对称短路电流计算结果

不对称短路包括单相接地短路和两相短路，其计算需考虑零序及负序网络特性。

### 220kV 侧 (K1点)
*   **单相接地短路**：总短路电流 ($I^{(1)}_{K1}$) 为 **1.778 kA**。
    *   计算公式：$I_{K1}^{(1)} = M \left( I_{A(1)}^{(1)} + I_{B(1)}^{(1)} \right) = 3 \times (0.219 + 0.374) = 1.778 \text{ kA}$。

### 110kV 侧 (K2点)
*   **单相接地短路**：总短路电流 ($I^{(1)}_{K2}$) 为 **3.34 kA**。
    *   计算公式：$I_{K2}^{(1)} = M \left( I_{A(1)}^{(1)} + I_{B(1)}^{(1)} \right) = 3 \times (0.479 + 0.615) = 3.34 \text{ kA}$。

### 10kV 侧 (K3点)
*   **单相接地短路**：总短路电流为 **0 kA**。
    *   原因：由于该侧零序电抗无穷大，各支路短路电流均为 0。
    *   计算公式：$I^{(1)}_{K3} = M(I^{(1)}_{A(1)} + I^{(1)}_{B(1)}) = 3(0 + 0) = 0 \text{ kA}$。
*   **两相短路**：总短路电流 ($I^{(2)}_{K3}$) 为 **19.075 kA**。
    *   计算公式：$I_{K3}^{(2)} = M \left( I_{A(1)}^{(2)} + I_{B(1)}^{(2)} \right) = \sqrt{3} \times (6.022 + 4.99) = 19.075 \text{ kA}$。

# RM6 SeT 安装与土建要求

## 概述
本页汇总 RM6 SeT 环网柜系统的安装尺寸、间距要求及电缆敷设规范，旨在指导现场施工布局与土建工程实施。内容基于 RM6 SeT 样本及安装连接章节的技术数据。

## 柜体尺寸与重量规格
RM6 SeT 柜体的物理尺寸随功能单元数量变化，具体规格如下：

| 功能数 | 柜体长度 (mm) | 柜体深度 (mm) | 重量 (kg) |
| :--- | :--- | :--- | :--- |
| 1 | 375/420 | 750 | 260 - 365 |
| 6 | 2170 | 750 | 700 - 970 |

此外，负荷开关柜/母线提升柜的标准尺寸为：
- **宽**：375 mm
- **深**：750 mm
- **高**：1950 mm（含 350 mm 低压间）

## 安装间距要求
为确保设备散热、维护空间及结构安全，RM6 SeT 单元在安装时需满足以下最小间距要求：

1. **到后墙的距离**：≥ 20 mm
2. **到房顶的距离**：≥ 100 mm
3. **侧面到墙的距离**：
   - **不可扩展侧面**：≥ 30 mm
   - **可扩展侧面**：≥ 450 mm

## 电缆敷设规范
针对干式绝缘单芯电缆的敷设，需遵循以下弯曲半径及电缆沟深度标准：

- **适用条件**：电缆截面积 ≤ 150 mm²
- **弯曲半径 (R)**：500 mm
- **电缆沟深度 (P1)**：400 mm

## 施工注意事项
- 在土建阶段，需预留足够的操作空间，特别是可扩展侧面需预留至少 450 mm 的净空。
- 电缆沟深度设计需考虑电缆弯曲半径要求，避免过度弯曲导致绝缘层受损。
- 柜体重量较大（最高可达 970 kg），基础承重及吊装方案需据此设计。

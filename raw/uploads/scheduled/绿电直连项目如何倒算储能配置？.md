绿电直连项目里的储能，不能简单按新能源装机比例配置。

比如“光伏装机的15%、2小时”，只能作为粗略参考，不能直接作为项目落地测算依据。

真正要算的是四件事：

**储能要搬移多少绿电？**

**储能要顶住多大功率？**

**储能能不能每天有效循环？**

**储能带来的收益能不能覆盖成本？**

所以，绿电直连项目的储能配置，不是从电源装机“正向配”，而是从项目目标“反向倒”。

## 一、先把储能拆成两个指标

储能配置通常写成：

**10MW/40MWh**

这里面有两个概念。

**MW，是功率。**

它决定储能某一时刻最多能充多少、放多少。

**MWh，是容量。**

它决定储能可以连续放多久。

比如10MW/40MWh，满功率放电大约可以持续4小时。

所以，倒算储能配置时，不能只问“配多少储能”。

要拆成两个问题：

**功率怎么倒算？**

**容量怎么倒算？**

功率看最大缺口。

容量看缺口持续时间和需要搬移的电量。

![](images/107de0645518.png)

## 二、第一步：准备四类基础数据

要倒算储能，至少要有四类数据。

| 数据类型 | 需要什么 | 用来算什么 |
| --- | --- | --- |
| 负荷数据 | 企业或园区逐时负荷，最好8760小时 | 算最大负荷、缺口时段、下网功率 |
| 电源数据 | 光伏、风电逐时出力 | 算绿电出力、富余电量 |
| 电网目标 | 目标接网容量、允许最大下网功率 | 倒算储能放电功率 |
| 电价参数 | 大网电价、绿电价格、容量电费、储能成本 | 校验经济性 |

如果暂时没有8760小时数据，至少要有典型日曲线。

但正式测算不能只拿一天数据下结论。

光伏要看不同季节，风电要看大小风季，工业负荷要看工作日、检修期和满产期。

## 三、第二步：先算无储能基准

倒算储能前，先做“不配储”的源荷匹配。

假设某一小时：

负荷为 `L`

新能源出力为 `G`

那么：

**直接消纳电量 = min（L，G）**

**富余绿电 = max（G - L，0）**

**大网下电 = max（L - G，0）**

把全年每个小时都算一遍，就能得到无储能情况下的基准结果。

| 指标 | 计算方式 | 含义 |
| --- | --- | --- |
| 直接消纳绿电 | 每小时 `min（L，G）` 累加 | 不配储时负荷直接吃掉多少绿电 |
| 富余绿电 | 每小时 `max（G-L，0）` 累加 | 储能可能搬移的电量池 |
| 大网下电量 | 每小时 `max（L-G，0）` 累加 | 仍需从公共电网购买的电量 |
| 最大下网功率 | `max（L-G）` | 项目对公共电网的最大容量需求 |
| 自发自用比例 | 直接消纳绿电 / 新能源发电量 | 绿电就近消纳水平 |

这一步决定储能有没有必要配。

如果不配储时，绿电已经基本被负荷消纳，储能就不能硬上。

如果中午大量富余、晚高峰大量下网，储能才有测算价值。

## 四、第三步：从自发自用目标倒算储能容量

绿电直连项目通常要提高自发自用比例。

如果项目有目标比例，就可以先倒算需要储能搬移多少电量。

公式是：

**目标自发自用电量 = 新能源发电量 × 目标自发自用比例**

**需新增自发自用电量 = 目标自发自用电量 - 无储能直接消纳电量**

这个“需新增自发自用电量”，就是储能全年大概要帮助搬移的电量。

但它不等于储能容量。

因为储能每天循环使用。

比如项目全年还差1500万千瓦时自发自用电量。

如果储能一年有效运行300天，则每天需要搬移：

**1500万千瓦时 ÷ 300天 = 5万千瓦时/天**

也就是：

**50MWh/天**

再考虑放电效率、可用SOC和衰减，名义容量要放大。

简单口径可以这样算：

**储能名义容量 = 每日需放电量 ÷ 放电效率 ÷ 可用SOC比例**

如果每日需要放电50MWh，放电效率按95%，可用SOC按90%，则：

**50 ÷ 0.95 ÷ 0.90 = 58.5MWh**

所以储能名义容量大约要按60MWh考虑。

## 五、第四步：从接网容量目标倒算储能功率

容量解决的是“搬多少电”。

功率解决的是“某一刻顶多大缺口”。

如果项目希望降低接入公共电网容量，就要倒算储能需要在峰值时段补多少功率。

公式是：

**储能需放电功率 = 负荷功率 - 新能源实时出力 - 目标接网容量 - 可调节负荷功率**

比如某一时刻：

园区负荷50MW。

新能源出力5MW。

目标接网容量35MW。

可调节负荷5MW。

那么储能需要补的功率是：

**50 - 5 - 35 - 5 = 5MW**

如果没有可调节负荷，则储能需要补：

**50 - 5 - 35 = 10MW**

所以，储能功率不是单独算出来的。

它和新能源实时出力、目标接网容量、负荷调节能力一起决定。

能调负荷，就可以少配储能。

不能调负荷，就只能靠储能硬顶，成本会明显上升。

![](images/453ebe984148.png)

## 六、第五步：从缺口持续时间判断储能时长

功率算出来以后，还要看缺口持续多久。

比如项目希望把下网功率控制在35MW以内。

某天18:00到22:00，净负荷一直超过35MW，平均超出10MW。

那么这个时段需要储能放电：

**10MW × 4小时 = 40MWh**

考虑放电效率和可用SOC：

**40 ÷ 0.95 ÷ 0.90 = 46.8MWh**

也就是说，仅覆盖这个晚高峰缺口，储能容量就要接近50MWh。

所以，储能时长不是拍脑袋定2小时、4小时。

缺口持续2小时，2小时储能可能够用。

缺口持续4小时，就要考虑4小时储能。

如果缺口跨日、跨周、跨季节，常规电化学储能就很难经济，需要结合风光互补、负荷调节、绿电交易和多能耦合一起解决。

## 七、第六步：把功率和容量合并

储能最终配置要同时满足两个维度。

**功率要够。**

能在峰值时段压住最大下网功率。

**容量要够。**

能搬移足够的绿电，覆盖关键缺口时段。

因此可以用两个公式做初步合并：

**储能功率 = max（消纳富余绿电需要的充电功率，压降下网功率需要的放电功率）**

**储能容量 = max（提高自发自用需要的容量，覆盖峰值缺口需要的容量）**

但这只是技术边界，不是最终投资方案。

如果前60MWh每天都能循环，后40MWh一年只用几十次，那么后40MWh就可能不经济。

绿电直连项目配储，不能追求技术上全覆盖，而要找经济上最优点。

## 八、第七步：做经济性校验

储能倒算出来以后，还要算收益。

绿电直连项目里的储能收益，主要有几类。

| 收益来源 | 怎么算 |
| --- | --- |
| 提高自发自用收益 | 新增自发自用电量 × 大网购电与内部绿电综合成本差 |
| 减少大网下电收益 | 减少下网电量 × 随下网电量发生的费用 |
| 容量压降收益 | 降低接网容量 × 容量电价 |
| 峰谷套利收益 | 低价充、高价放形成价差 |
| 需求响应或市场收益 | 按当地政策和实际参与规则测算 |

但基准测算里，不建议把所有收益都堆上去。

确定性收益进基准测算。

不确定收益进敏感性测算。

比如容量压降，必须看电网是否认可新的接网容量。

如果容量压降不能落到结算里，就不能把这部分收益直接算进基准收益。

## 九、一个简化例子：倒算储能配置

假设某工业园区做绿电直连，基础数据如下：

| 项目 | 数据 |
| --- | --- |
| 园区最大负荷 | 50MW |
| 日用电量 | 910MWh |
| 光伏日发电量 | 440MWh |
| 无储能直接消纳绿电 | 340MWh |
| 无储能富余绿电 | 100MWh |
| 无储能最大下网功率 | 50MW |
| 目标自发自用比例 | 90% |
| 目标接网容量 | 40MW |
| 储能放电效率 | 95% |
| 可用SOC比例 | 90% |

### 1. 先算自发自用目标

光伏日发电量为440MWh。

目标自发自用比例为90%。

所以目标自发自用电量为：

**440 × 90% = 396MWh**

无储能时，园区直接消纳绿电340MWh。

所以还差：

**396 - 340 = 56MWh**

也就是说，储能每天至少要多搬移56MWh绿电，才能把自发自用比例提高到90%。

考虑放电效率和可用SOC：

**56 ÷ 0.95 ÷ 0.90 = 65.5MWh**

所以，从自发自用目标看，储能容量至少要接近：

**70MWh**

### 2. 再算接网容量目标

项目希望把接网容量从50MW降到40MW。

晚高峰时段，园区负荷50MW，光伏基本无出力。

如果没有可调节负荷，那么储能需要顶住：

**50 - 40 = 10MW**

这个缺口持续4小时。

所以需要放电电量：

**10MW × 4小时 = 40MWh**

考虑效率和可用SOC：

**40 ÷ 0.95 ÷ 0.90 = 46.8MWh**

所以，从接网容量目标看，储能至少需要：

**10MW/50MWh左右**

### 3. 合并两个结果

从自发自用目标看，需要约70MWh容量。

从接网容量目标看，需要约10MW功率、50MWh容量。

再看中午光伏富余情况。

中午富余绿电约100MWh，持续4小时，平均富余功率约25MW。

但项目只需要搬移56MWh。

如果储能充电功率按15MW配置，4小时可充电约60MWh，基本可以满足目标。

因此，可以形成一个初步配置：

**15MW/70MWh**

这个配置不是按光伏装机比例拍出来的，而是从两个目标倒推出来的。

功率侧，15MW可以覆盖10MW晚高峰缺口，并留有调度余量。

容量侧，70MWh可以满足每日约56MWh新增自发自用电量的搬移需求。

## 十、再看这套配置是否划算

假设经济参数如下：

| 项目 | 假设值 |
| --- | --- |
| 大网综合变量电价 | 0.60元/千瓦时 |
| 内部绿电综合成本 | 0.36元/千瓦时 |
| 新增自发自用电量 | 56MWh/天 |
| 年有效运行天数 | 300天 |
| 接网容量压降 | 10MW |
| 容量电价 | 51.9元/kW·月 |
| 储能投资成本 | 650元/kWh |
| 储能规模 | 70MWh |
| 运维成本 | 投资额1%/年 |

先算新增自发自用收益：

**56,000千瓦时/天 ×（0.60 - 0.36）元/千瓦时 × 300天**

= **403.2万元/年**

再算容量压降收益：

**10,000kW × 51.9元/kW·月 × 12个月**

= **622.8万元/年**

合计年收益约：

**403.2 + 622.8 = 1026万元/年**

储能投资为：

**70,000kWh × 650元/kWh = 4550万元**

年运维成本约：

**4550万元 × 1% = 45.5万元/年**

扣除运维后，年净收益约：

**1026 - 45.5 = 980.5万元/年**

静态回收期约：

**4550 ÷ 980.5 = 4.6年**

这个结果看起来可以。

但前提是：

**接网容量真的能从50MW降到40MW，并且这个容量压降能在结算中体现。**

如果容量压降不被认可，只剩新增自发自用收益，那么年净收益为：

**403.2 - 45.5 = 357.7万元/年**

静态回收期变成：

**4550 ÷ 357.7 = 12.7年**

这就完全是另一回事。

所以，绿电直连项目倒算储能，最关键的不只是技术参数，而是储能带来的收益能不能落到账上。

## 十一、小结

绿电直连项目倒算储能配置，按以下顺序：

第一，整理负荷曲线和新能源出力曲线。

第二，先算无储能情况下的直接消纳、富余绿电、大网下电和最大下网功率。

第三，从自发自用目标倒算需要搬移的电量，得到储能容量边界。

第四，从目标接网容量倒算峰值缺口，得到储能功率边界。

第五，结合缺口持续时间，判断储能时长。

第六，把功率和容量结果合并，形成多个配置方案。

第七，用新增自发自用收益、容量压降收益、峰谷价差收益和储能投资成本做经济性校验。

**绿电直连项目里的储能，不是按新能源装机比例配出来的，而是从源荷错配、接网容量和经济性目标倒算出来的。**

配少了，自发自用比例上不去，容量也压不下来。

配多了，投资成本吃掉收益，项目反而更难落地。

真正合理的储能配置，是刚好补在项目最有价值的那一段缺口上，大概逻辑就是这样。

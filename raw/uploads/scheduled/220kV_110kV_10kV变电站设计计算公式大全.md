$$I _ { m a x } = 1 . 0 5 \frac { S _ { N } } { \sqrt { 3 } U _ { N } } = 1 . 0 5 \times \frac { 2 \times 1 0 } { \sqrt { 3 } \times 1 0 . 5 } = 1 . 2 1 2 \ ( A )$$

所以选择额定电流为 1500A，额定电压为 10kV 的电抗器

电抗百分数的选择：

$$X \% \geq \left( \frac { S _ { B } } { S ^ { \prime \prime } } - X _ { c a * } \right) \frac { U _ { B } } { I _ { B } } \frac { I _ { N * } } { U _ { N * } } \times 1 0 0 \%$$

$$= \left( \frac { 1 0 0 } { 2 5 \times \sqrt { 3 } \times 1 0 . 5 } - \frac { 0 . 2 6 5 \times 0 . 3 1 9 3 } { 0 . 2 6 5 + 0 . 3 1 9 3 } \times \frac { 1 0 . 5 \times 5 . 6 } { 1 0 0 } \right) \frac { 1 0 . 5 } { 5 6 0 0 } \frac { 1 5 0 0 } { 1 0 } \times 1 0 0 \% = 6 . 7 9 \%$$

所以备选型号为 XKGKL-10-1500-8 的电抗器。

进行电压损失校验 $U \% = X \% \frac { I _ { m a x } } { I _ { N * } } \sin \varphi = 8 \% \times \frac { 1 . 2 1 2 } { 1 . 5 } \times 0 . 5 2 = 3 . 3 6 \% < 5 \%$

故选择型号为 XKGKL-10-1500-8 的电抗器

第 3 章 主变压器保护的整定运算

3.1 变压器的主保护

变压器的主保护为瓦斯保护和纵差保护。瓦斯保护主要应用于匝间短路，铁芯故障、绝缘性能下降、油面降低、变压器绕组断线等，油箱里发生故障时，导致变压器油体积膨胀甚至被分解产生气体，变压器油箱内部压力升高，导致瓦斯继电器动作，瓦斯保护有轻、重瓦斯两种，分别对应信号和跳闸两种动作。而纵差保护作为主保护就是正常的电气量保护，动作快而灵敏。

3.1.1 轻瓦斯保护整定

当油箱里发生故障时，导致变压器油体积膨胀甚至被分解产生气体，变压器油箱内部压力升高，导致油箱内部气体容积变化，通过继电器来检测这种容积变化，变化范围超过整定值后继电器会动作。

本设计的主变容量较大，气体容积计算范围取整定值为 280cm³。当变压器出现油面的降低，发出“轻瓦斯保护”信号，使我们的工作人员能尽快处理故障。

3.1.2 重瓦斯保护整定

在现实工作的环境中我们会遇到变压器里面发生特别重大的故障，这就会使变压器油变成气体，气体吹到变压器的挡板，然后继电器就会触发发出信号，最后各侧断路器就会相继断开，这就是重瓦斯保护。

本设计的变压器容量为 180MVA，又采用的是强油循环，所以油流速度整定为 1.1m/s。当油的流速大于整定值后，继电器会动作，直接对应跳闸

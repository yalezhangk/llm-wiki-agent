# 三工位开关与机械联锁

## 概述
在 RM6 SeT 中压开关柜中，三工位开关（Three-position switch）是核心操作元件，其设计旨在通过机械结构确保操作的安全性和逻辑正确性。该组件通常具备天然互锁特性，并可选配接地可视窗口以增强状态确认能力。

## 工作原理
三工位负荷开关（C功能）通过在同一时刻仅允许触点处于一个位置的方式，确保电气连接的唯一性。这种设计从根本上防止了带电母线接地的危险情况，从而保证了设备的安全运行。

## 机械联锁逻辑
RM6 SeT 通过一系列机械联锁机制防止误操作，具体逻辑如下：

1. **电缆室联锁**：为防止人员误入带电间隔，电缆室门仅在开关处于接地位置时才能打开。
2. **熔断器室联锁**：熔断器室与接地开关存在机械联锁关系，只有在完成接地操作后，熔断器室门方可开启。
3. **隔离开关联锁**：隔离开关的分合闸操作受到严格限制，必须满足断路器处于分闸位置且电缆室门处于关闭状态这两个条件。

## 安全意义
这些联锁逻辑共同构成了 RM6 SeT 的安全屏障，确保在维护、检修或操作过程中，操作人员不会意外接触带电部件，同时防止因操作顺序错误导致的电气事故。

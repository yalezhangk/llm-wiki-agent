# 一、核心定义

10kV 真空断路器（常用型号 VS1、ZN63A、ZN28 等），灭弧介质为高真空腔体，依靠真空绝缘熄弧，是 10kV 配电室最主流的分合开关；负责正常负荷合闸送电、正常分闸停电，故障（短路、过载、接地）时快速跳闸切断故障回路。

![](images/4b48ae877b6e.png)

# 二、核心设备

1.真空灭弧室：设备的核心部件，内部维持10⁻⁴~10⁻⁶Pa的超高真空，内置铜铬合金动静触头、屏蔽罩和密封波纹管，负责实现快速熄弧。

2.操动机构：主流为弹簧机构或永磁机构，驱动触头完成分合闸动作，永磁机构机械寿命可达30000次以上，分闸响应速度≤30ms。

3.支撑绝缘件：由环氧树脂或陶瓷材质构成，承担对地绝缘和结构支撑作用。

# 三、合闸原理

储能电机提前给合闸弹簧储能（手动储能摇把也可手动储能），弹簧处于蓄能拉紧状态；

合闸回路通电，合闸电磁铁动作解锁，合闸弹簧释放，通过机构、绝缘拉杆向上推动动触头；

动静触头高速闭合压紧，依靠触头弹簧保证合闸后触头有足够压力；

合闸到位后机构锁扣保持合闸位置，同时合闸弹簧释放后电机自动再次储能，为下一次分闸、重合闸做准备。

# 四、分闸原理

弹簧机构储能完毕，接到分闸指令，分闸线圈得电，触发机构脱扣，储能分闸弹簧释放拉力，通过连杆、绝缘拉杆拉动灭弧室内部动触头向下运动，动静触头强行分离。

# 五、ABB真空断路器的灭弧原理

![](images/55209b21dfc7.png)

# 

1.真空断路器不需要灭弧和绝缘的介质。实际上，灭弧室中不存在可被电离的物质。在任何情况下，当触头分离时，触头间的电弧通道仅仅由触头材料的金属蒸气构成。

2.电弧只能由外部能量维持，当主回路电流在自然过零点时刻消失，电弧即不能维持。在此刻，急速下降的载流密度和快速凝聚的真空金属蒸气，使触头之间迅速恢复了绝缘。真空灭弧室因此恢复了绝缘能力以及耐受系统瞬态恢复电压的能力，最终将电弧熄灭。

3.即使在很小的开距下，真空也有很高的绝缘强度，因此只要在电流过零点的数毫秒之前将真空灭弧室的触头分开，即能保证成功开断。

4.特殊设计的触头几何形状和触头材质，以及很短的燃弧时间和极低的电弧电压，使触头烧蚀程度非常低，保证了灭弧室的长寿命。此外，真空还可以防止触头被氧化和污染。

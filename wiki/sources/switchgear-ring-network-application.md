## Summary
本文是一篇关于中压开关柜在环网（Ring Main）应用场景下的技术综述。文章首先澄清了“环网柜”（RMU）的定义：它本质上是一种应用方式（Ring进、Ring出 + Main主进/出线），而非单一的柜型。在中国，RMU通常特指用于二次配电的紧凑型气体绝缘开关柜（630A/20kA）。文章重点分析了随着新能源（风电）和数据中心应用的发展，环网应用对电流（高达4000A）和短路容量（40kA）的需求激增，导致传统紧凑型RMU无法满足需求。文章对比了空气绝缘、固体绝缘和环保气体绝缘开关柜在数据中心等空间受限场景下的适用性，指出环保气体绝缘开关柜因尺寸紧凑（深度小、可靠墙安装）而成为高电流环网应用的首选，而户外开关柜则适用于对空间不敏感但追求成本和灵活性的场景。

## Key Claims
- **RMU定义澄清**：RMU（Ring Main Unit）是“环路进、环路出加主进/出线”的应用单元，而非特定柜型。在中国，它常被特定化为二次配电用的紧凑型气体绝缘开关柜（630A/20kA）。
- **应用范围扩展**：随着新能源和数据中心发展，环网应用不再局限于传统二次配电，电流需求从630A扩展至4000A，短路电流从20kA扩展至40kA。
- **新能源应用**：风电场中，每台风机发电后通过“手拉手”环网单元集中电力，经升压站输送至电网。
- **数据中心应用**：为保证供电可靠性，数据中心采用环网供电方式分配高压电至电力模块。由于电流大（如38kV 1250A/31.5kA）且空间受限（宽≤750mm, 深≤1200mm），空气绝缘无法实现，固体绝缘需特殊柜型，而**环保气体绝缘开关柜**因尺寸紧凑（相当于空气绝缘50%占地面积，深度小可靠墙安装）而最适合。
- **户外开关柜应用**：对于对安装空间无要求、但对价格和扩展灵活性敏感的应用，38kV户外开关柜（垫式安装）是合适选择，如环进、电源模块出线、环出三台一组。
- **智能化趋势**：远程操控需求使得环网应用倾向于使用断路器方案（三工位隔离开关+固定式断路器，或手车式断路器），而非传统的负荷开关/熔断器组合。

## Key Quotes
> "RMU（Ring Main Unit），Ring-环路，Main-主开关，Unit-单元。环网柜是应用在环路电网供电的开关柜，环网柜是一种应用方式的开关柜...而不是柜型。"

> "随着新能源、数据中心应用，环网应用的范围不断扩大，电流不断增大，短路电流也大幅增加，如额定电流达4000A，短路、短时耐受电流达40kA。"

> "环保气体绝缘开关柜则非常适合环网应用...尺寸紧凑，相当于空气绝缘开关柜占地面积的50%，关键是深度小，可以靠墙安装，适用于集装箱安装。"
